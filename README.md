# Form Monorepo

Monorepo with "form" component in two versions: vanilla JavaScript and React.

## Design

[Figma](https://www.figma.com/design/mmJy8BwGYUHHcRfypE5aPL/FORM_Mate)

## Installation

```bash
npm install
```

## Running

```bash
npm run dev -w vanilla    # Vanilla JS
npm run dev -w react      # React
```

## Structure

```
packages/
├── vanilla/    # Pure JavaScript + Vite
└── react/      # React 19 + Vite
```
